# Glosario

| Término | Significado dentro del proyecto |
|---|---|
| ADR | registro breve de una decisión arquitectónica, su contexto y consecuencias |
| Aggregate root | entidad que protege las invariantes de un conjunto transaccional |
| Autenticación | comprobación de quién es el usuario |
| Autorización | decisión sobre qué puede hacer el usuario autenticado |
| Correlation ID | identificador que enlaza logs producidos por una misma petición |
| DTO | estructura de entrada o salida independiente del modelo persistente |
| Idempotencia | propiedad por la que repetir una operación no duplica su efecto |
| Ledger | historial inmutable de movimientos que explica un saldo |
| Monolito modular | aplicación desplegada como unidad, dividida internamente por dominios claros |
| OIDC | capa de identidad construida sobre OAuth 2.0 |
| Permission | capacidad concreta, como confirmar una venta o leer auditoría |
| Problem Details | formato estándar para describir errores HTTP de forma procesable |
| RBAC | autorización basada en roles que agrupan permisos |
| RPO | pérdida máxima de datos tolerable medida en tiempo |
| RTO | tiempo máximo objetivo para recuperar el servicio |
| Soft delete | desactivación lógica que preserva referencias e historia |
| Vertical slice | funcionalidad completa desde API hasta persistencia y prueba |
